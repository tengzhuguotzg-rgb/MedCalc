# Batch 1a 计算器验证用例

本文件记录 Batch 1a 新增计算器的公式口径与手动核对用例。阈值如有院内检验 ULN，应以本院标准复核。

## Shock Index
- 公式：SI = HR / SBP。
- 用例：HR 120、SBP 90 → SI 1.33，应为高危提示。
- 用例：HR 70、SBP 120 → SI 0.58，应为正常/低危。

## qSOFA
- 标准：RR ≥22、SBP ≤100、意识改变（GCS <15 或 consciousness 非 alert）各 1 分。
- 用例：RR 24、SBP 98、GCS 14 → 3 分，高风险。
- 用例：RR 16、SBP 120、GCS 15 → 0 分，低风险。
- 注意：qSOFA 是筛查工具，不单独诊断脓毒症。

## RTS（Revised Trauma Score）
- coded：GCS/SBP/RR 各 0-4，总分 0-12；另显示加权 RTS = 0.9368×GCScode + 0.7326×SBPcode + 0.2908×RRcode。
- 用例：GCS 15、SBP 120、RR 16 → coded 12，weighted ≈ 7.84。
- 用例：GCS 3、SBP 0、RR 0 → coded 0，weighted 0，危重。

## RSBI
- 公式：RSBI = RR / VT(L) = RR × 1000 / VT(mL)。
- 用例：RR 25、VT 400 mL → 62.5，偏低风险。
- 用例：RR 35、VT 250 mL → 140，撤机失败风险高。
- 注意：仅自主呼吸/SBT 条件下解释；机械通气控制通气下不用于撤机判断。

## HELLP 标准核对
- 核对口径：血小板 <100×10⁹/L；AST 或 ALT 明显升高（本版按 ≥80 U/L 近似 2×ULN，未按本院 ULN 校正）；溶血证据满足其一：hemolysis=1、LDH ≥600 U/L、总胆红素 ≥1.2 mg/dL（约 20.5 μmol/L）。
- 用例：PLT 80、AST 120、LDH 700 → 三项满足，提示满足 HELLP 标准。
- 用例：PLT 150、AST 45、LDH 300 → 不支持。
- 注意：输出为标准核对/分层，不是最终诊断；需结合妊娠/产后、血压、蛋白尿、临床表现，并鉴别 TTP/HUS/aHUS/妊娠期急性脂肪肝。

## 代谢组合（校正钙 + 计算渗透压/渗透间隙）
- 校正钙：corrected Ca = measured Ca + 0.02 × (40 - albumin g/L)，白蛋白 g/dL 需 ×10 转 g/L。
- 用例：Ca 1.8、Alb 25 g/L → corrected Ca = 1.8 + 0.02×15 = 2.10 mmol/L。
- 计算渗透压：2×Na + Glu + BUN（均 mmol/L）。渗透间隙 = measuredOsm - calculatedOsm；>10 提示渗透活性物质。
- 用例：Na 140、Glu 5、BUN 5、measuredOsm 305 → calc 290，gap 15，提示高渗透间隙。

# Batch 1b

## HEART 评分
- 公式：H（病史 0-2）+ E（心电图 0-2）+ A（年龄 <45=0 / 45-64=1 / ≥65=2）+ R（危险因素 0 个=0 / 1-2 个=1 / ≥3 个或已知动脉粥样硬化=2）+ T（肌钙蛋白 ≤ULN=0 / 1-3×ULN=1 / >3×ULN=2）。
- 用例：H2、E2、年龄 70（A2）、危险因素 3 个（R2）、cTn 0.5/ULN 0.04（T2）→ 10 分，高风险。
- 用例：H0、E0、年龄 40（A0）、危险因素 0（R0）、cTn ≤ULN（T0）→ 0 分，低风险。
- 注意：肌钙蛋白与 ULN 必须同单位；自动计算时未填病史/心电图按 0 分计，可能低估。

## Glasgow-Blatchford（GBS）
- 公式：BUN mg/dL（18.2-22.3=2 / 22.4-28=3 / 28.1-70=4 / >70=6）+ Hgb g/dL（男 <10=6 / 10-11.9=3 / 12-12.9=1；女 <10=6 / 10-11.9=1）+ SBP（<90=3 / 90-99=2 / 100-109=1）+ HR≥100=1 + 黑便=1 + 晕厥=2 + 肝病=2 + 心衰=2。
- 用例（MDCalc 经典）：男，BUN 20、Hgb 13.5、SBP 115、HR 90，无伴随项 → 2+1+0+0=3 分。
- 用例：女，BUN 75、Hgb 9、SBP 85、HR 110、黑便+晕厥+心衰 → 6+6+3+1+1+2+2=21 分，高风险。
- 单位换算：病历 bun 字段为尿素 mmol/L，自动计算按 ×2.8 转 BUN mg/dL；hgb g/L ÷10 转 g/dL。
- 注意：仅用于上消化道出血。

## BISAP
- 公式：BUN>25 mg/dL、GCS<15、SIRS≥2、年龄>60、胸腔积液，各 1 分。
- 用例：BUN 10 mmol/L（≈28 mg/dL）✓、GCS 15、SIRS 3✓、年龄 65✓、无胸腔积液 → 3 分，高风险。
- 用例：BUN 5、GCS 15、SIRS 1、年龄 45、无胸腔积液 → 0 分，低风险。

## Ranson
- 入院项：年龄>55、WBC>16、血糖>11.1 mmol/L、LDH>350、AST>250；48h 项：Hct 下降>10%、BUN 上升>5 mg/dL、Ca<2.0 mmol/L、PaO₂<60、碱缺失>4、液体隔离>6L。
- 用例：年龄 60、WBC 18、Glu 12、LDH 400、AST 300 → 入院 5/5；不填 48h 项时总分 5，重症倾向。
- 注意：48h 项留空不计分，脚注会标明仅为入院项。

## Cairo-Bishop TLS
- 实验室项（绝对值口径）：尿酸 ≥476 μmol/L、K ≥6.0、P ≥1.45 mmol/L、Ca ≤1.75 mmol/L，≥2 项 = 实验室 TLS；叠加肌酐 ≥1.5×ULN / 心律失常 / 抽搐 = 临床 TLS。
- 用例：尿酸 600、K 6.5、P 1.2、Ca 2.0 → 2 项，实验室 TLS。
- 用例：上述 + 肌酐 1.6×ULN → 临床 TLS。
- 用例：尿酸 400、K 4.5、P 1.0、Ca 2.2 → 0 项，不满足。
- 注意：Cairo-Bishop 原文还接受“较基线变化 25%”口径，本工具按绝对值口径，脚注已注明。

## Burch-Wartofsky（BWPS）
- 体温（37.2-37.7=5 … ≥40=30）+ HR（100-109=5 … ≥140=25）+ CNS（0/10/20/30）+ GI（0/10/20）+ CHF（0/5/10/15）+ 房颤 10 + 诱因 10。
- 用例：T 39.5（25）、HR 145（25）、谵妄（20）、腹泻（10）、无 CHF、房颤（10）、诱因（10）→ 100 分，高度提示危象。
- 用例：T 37.0（0）、HR 90（0）、其余 0 → 0 分，不太支持。

## Wells DVT
- 9 项各 +1（活动性肿瘤、下肢制动/石膏、卧床>3天或12周内手术、深静脉走行压痛、整条腿肿胀、小腿周径差≥3cm、患侧凹陷性水肿、浅表侧支静脉、既往DVT），替代诊断更可能 -2。
- 用例：小腿周径差 + 压痛 + 制动 → 3 分，高概率。
- 用例：仅水肿 + 替代诊断 → -1 分，低概率。
- 注意：手动计算器，不接病历自动计算（无客观数据锚点）；与 Wells PE 不混用。

## CPIS/VAP
- 体温（36.5-38.4=0 / 38.5-38.9=1 / ≥39 或 ≤36=2）+ WBC（4-11=0 / <4 或 >11=1 / 伴杆状核≥50%=2）+ 分泌物（0/1/2）+ 氧合（P/F≤240 且非 ARDS=2）+ 胸片（0/1/2）+ 培养（0/1/2）。
- 用例：T 39.2（2）、WBC 14（1）、脓性分泌物（2）、P/F 200（2）、局灶浸润（2）、培养未送（0）→ 9 分，VAP 可能性高。
- 注意：辅助工具，不能单独诊断 VAP；自动计算时未填项按 0 分计可能低估。

## ANC + MASCC
- ANC：直接录入优先，否则 WBC × 中性粒%/100。分层：<0.5 重度 / 0.5-1.0 中度 / 1.0-1.5 轻度。
- 用例：WBC 1.2、中性粒 30% → ANC 0.36 ×10⁹/L，重度粒缺。
- MASCC：疾病负担 无/轻 5、中 3、重 0；无低血压 5；无 COPD 4；实体瘤或无真菌感染 4；无脱水 3；门诊状态 3；年龄<60 2。≥21 低危。
- 用例：负担轻（5）+ 无低血压（5）+ 无COPD（4）+ 实体瘤（4）+ 无脱水（3）+ 门诊（3）+ 年龄 50（2）→ 26 分，低危。
- 注意：MASCC 仅用于发热性中性粒细胞减少患者；自动计算只算 ANC，MASCC 手动。

# Batch 2a

## ADHERE 心衰风险
- 三因子：BUN≥43 mg/dL、SBP<115 mmHg、Cr≥2.75 mg/dL；住院死亡率 0/1/2/3 因子 ≈ 2%/6%/13%/20-40%。
- 用例：BUN 20 mmol/L（56 mg/dL）、SBP 100、Cr 260 μmol/L（2.94 mg/dL）→ 3 因子，极高危。
- 用例：BUN 6、SBP 130、Cr 90 → 0 因子，低危。
- 换算：病历 bun 为尿素 mmol/L ×2.8；creatinine 按 crUnit 换算（μmol/L ÷88.4）。

## STESS
- 意识（清醒/嗜睡模糊=0，木僵/昏迷=1）+ 发作类型（非GTCS=0/GTCS=1/昏迷中NCSE=2）+ 年龄≥65=2 + 无癫痫史=1。0-6 分。
- 用例：GTCS（1）+ 清醒（0）+ 40 岁（0）+ 有癫痫史（0）→ 1 分，低死亡风险。
- 用例：木僵（1）+ NCSE（2）+ 70 岁（2）+ 无癫痫史（1）→ 6 分，高死亡风险。
- 手动计算器，不接自动计算。

## McMahon 横纹肌溶解
- 年龄 >50=1.5 / >70=3 / >80=4.5（取最高档不累计）；女性 1；Cr 1.5-2.2 mg/dL=1.5 / >2.2=3；CK>40000=3；P 4-5.4 mg/dL=1.5 / >5.4=3；HCO₃<19=3；Ca≤7.5 mg/dL=1.5；非低危病因（非癫痫/晕厥/运动/他汀/肌炎）=3。
- 用例（MDCalc 验证向）：60 岁男、CK 5000、Cr 1.0 mg/dL（88 μmol/L）、低危病因 → 1.5 分，低危。
- 用例：75 岁女、CK 50000、Cr 3.0 mg/dL（265 μmol/L）、P 1.9 mmol/L（5.9 mg/dL）、Ca 1.7 mmol/L（6.8 mg/dL）、HCO₃ 15、挤压伤 → 3+1+3+3+3+1.5+3+3=21.5 分，高危。
- 换算：P mmol/L×3.1=mg/dL；Ca mmol/L×4=mg/dL；Cr μmol/L÷88.4=mg/dL。
- 注意：自动计算病因默认按“其他病因”计 3 分（保守），脚注已注明。

## ISTH 显性 DIC
- 血小板（>100=0 / 50-100=1 / <50=2）+ 纤溶标志物（无=0/中=2/重=3）+ PT 延长（<3s=0/3-6s=1/>6s=2）+ 纤维蛋白原（>1.0=0/<1.0=1）。≥5 = 显性 DIC。
- 用例：PLT 40（2）+ D-二聚体重度（3）+ PT 延长 4s（1）+ Fib 1.8（0）→ 6 分，显性 DIC。
- 用例：PLT 150 + 无升高 + PT 正常 + Fib 3 → 0 分。
- 自动计算 D-二聚体档位：<1 mg/L=0，1-5=2，>5=3（本院界值需核对，脚注已注明）。

## PLASMIC
- PLT<30、溶血证据、无活动性肿瘤、无移植史、MCV<90、INR<1.5、Cr<2.0 mg/dL，各 1 分。6-7 高 / 5 中 / 0-4 低。
- 用例：PLT 20✓、溶血✓、无肿瘤✓、无移植✓、MCV 85✓、INR 1.1✓、Cr 1.5✓ → 7 分，高风险。
- 自动计算溶血证据：hemolysis=1 或 retic>2.5% 或间接胆红素>34 μmol/L（≈2 mg/dL）。

## VIS
- VIS = 多巴胺+多巴酚丁胺 + 100×(肾上腺素+去甲肾上腺素) + 10×米力农 + 10000×血管加压素(U/kg/min)。
- 用例：去甲肾 0.2 μg/kg/min → VIS 20，中等支持。
- 用例：去甲肾 0.5 + 肾上腺素 0.1 → VIS 60，高负荷。
- 手动计算器（剂量暂不自动提取）。

## 乳酸清除率
- (lac0-lac1)/lac0×100%；≥10% 良好，<10% 不足，负值上升。
- 用例：4.0 → 2.8 → 30%，清除良好。
- 用例：4.0 → 3.8 → 5%，清除不足。
- 自动计算字段 lac0/lac1（血气域新增）。

## ABC/2
- 体积 = A×B×C/2；<30 mL 小量 / 30-60 中量 / >60 大量。
- 用例：A 5、B 4、C 3 → 30 mL，中量。
- 用例：A 6、B 5、C 5 → 75 mL，大量。
- 手动计算器（CT 测量值）。

## 年龄校正 D-二聚体
- 年龄>50：阈值 = 年龄×10 ng/mL FEU = 年龄/100 mg/L FEU；≤50：0.5 mg/L FEU。
- 用例：70 岁、D-二聚体 0.6 mg/L FEU → 阈值 0.7，低于阈值（低/中验前概率可助排）。
- 用例：40 岁、0.6 → 阈值 0.5，高于阈值。
- 注意：仅 FEU 单位；DDU 需换算。

## ADD-RS
- 高危基础/疼痛/查体各 1 分。0 低 / 1 中 / ≥2 高（直接影像）；可选 D-二聚体辅助排除。
- 用例：撕裂样痛 + 脉搏差 → 2 分，高风险。
- 用例：仅突发疼痛 + D-二聚体 0.3 → 1 分，中风险，D-二聚体支持排除策略。
- 手动计算器。

# Batch 2b

## 哮喘急性加重分级（GINA 口径）
- 取最差项：PEF <50%预计值、说话成短语/单词、RR≥30、HR≥120 → 重度；PEF <33%、沉默胸 → 危重。
- 用例：PEF 40%、说话成短语 → 重度。
- 用例：PEF 30% 或沉默胸 → 危重。
- 自动计算锚点 pefPct；说话能力/沉默胸为可选补充。

## GOLD ABE
- 症状多 = mMRC≥2 或 CAT≥10；高风险 = ≥2 次中度加重或 ≥1 次住院加重。症状少+低风险=A，症状多+低风险=B，高风险=E（不论症状）。
- 用例：mMRC 1、加重 1 次无住院 → A 组。
- 用例：mMRC 3、加重 1 次无住院 → B 组。
- 用例：mMRC 1、加重 3 次 → E 组。
- 注意：mmrc/cat 用 -1 表示未填。

## BAP-65
- BUN>25 mg/dL、意识改变、脉搏>109、年龄>65 各 1 分；I-II 低危 / III 中危 / IV 高危 / V 极高危。
- 用例：BUN 12 mmol/L（33.6 mg/dL）✓、意识清楚、HR 115✓、70 岁✓ → 3 分，IV 级。
- 用例：BUN 5、清楚、HR 90、50 岁 → 0 分，I 级。
- 自动计算意识改变 = GCS<15 或 confusion=1；bun 字段 ×2.8 换算。

## GCS-Pupils
- GCS-P = GCS - 瞳孔分（双侧有反应 0 / 一侧 1 / 均无 2），范围 1-15。
- 用例：GCS 7 + 一侧瞳孔无反应 → GCS-P 6，重型。
- 用例：GCS 15 + 双侧有反应 → 15，轻型。

## FOUR 评分
- E/M/B/R 各 0-4。用例：E4+M4+B4+R4=16；E0+M0+B0+R0=0（极重）。
- 手动计算器（脑干反射/呼吸模式无法自动提取）。

## CRUSADE
- 用例（MDCalc 验证向）：Hct 35（3）+ CrCl 45（28）+ HR 95（6）+ 男性 + 无心衰/血管病/DM + SBP 130（1）→ 38 分，中危 ≈8.6%。
- 用例：Hct 45（0）+ CrCl 100（7）+ HR 70（0）+ 男 + SBP 140（1）→ 8 分，极低危 ≈3.1%。
- 自动计算：hct、gfr（近似 CrCl，脚注注明）、hr、sbp；chf/vasc/dm 复用心脏域字段。

## REMS
- 年龄（<45=0/45-54=2/55-64=3/65-74=5/>74=6）+ MAP/HR/RR/SpO₂/GCS 各 0-4。0-26 分。
- 用例：40 岁，MAP 90、HR 90、RR 18、SpO₂ 98、GCS 15 → 0 分，低危。
- 用例：80 岁（6），MAP 45（4）、HR 130（2）、RR 36（3）、SpO₂ 80（3）、GCS 9（2）→ 20 分，极高危。
- 自动计算：age/map/hr/rr/spo2/gcs 全部已有字段。

## 吸入性肺炎风险核对
- 6 项危险因素（吞咽困难/意识障碍/呕吐反流/鼻饲管/镇静/口腔卫生差）计数：0-1 低 / 2-3 中 / ≥4 高。
- 用例：意识障碍+鼻饲+镇静+口腔差 → 4 项，高风险。
- 注意：非验证评分，已明确标注为核对清单；手动使用。

## 暂缓项记录
- CART、ACTION-ICU：回归系数模型且与 NEWS2 场景重叠，需核对原文系数后再实现。

# Batch 3a

## Parkland 烧伤补液
- 总量 = 4 mL × kg × %TBSA（LR），前 8h 一半（自受伤时刻起算），后 16h 另一半。
- 用例：70 kg、TBSA 40% → 11200 mL；前 8h 5600（700 mL/h），后 16h 5600（350 mL/h）。
- 注意：仅 II°及以上计入 TBSA；按尿量滴定（≥0.5 mL/kg/h）。

## QTc
- Bazett = QT/√RR（s）；附 Fridericia（立方根）、Framingham（QT+154×(1-RR)）、Hodges（QT+1.75×(HR-60)）。
- 用例：QT 400 ms、HR 75（RR 0.8s）→ Bazett ≈447 ms。
- 用例：QT 400 ms、HR 120（RR 0.5s）→ Bazett ≈566 ms（显著延长，且 Bazett 高心率误差大，看 Fridericia ≈504）。
- 自动计算锚点 hr + qtMs。

## Alvarado（MANTRELS）
- 转移痛1+厌食1+恶心呕吐1+右下腹压痛2+反跳痛1+发热(≥37.3)1+WBC>10 2+左移(中性粒>75%)1。
- 用例：右下腹压痛（2）+反跳痛（1）+WBC 12（2）+T 37.8（1）→ 6 分，中间区。
- 自动计算左移用 neutPct>75%。

## RIPASA
- 男1、年龄<40 1、右下腹痛0.5、转移痛0.5、厌食1、恶心呕吐1、病程<48h 1、右下腹压痛1、肌紧张2、反跳痛1、Rovsing 2、发热1、WBC升高1、尿检阴性1（不含 Foreign NRIC，满分 15.5）。
- 用例：男25岁+右下腹痛+压痛+肌紧张+WBC 13 → 1+1+0.5+1+2+1=6.5，低概率区。
- >12 高 / 8-12 中 / 5-7.5 低 / <5 不太可能。

## 脑脊液解读
- 细菌性特征：WBC≥1000、中性粒≥80%、蛋白≥1.5 g/L、CSF糖/血糖<0.4；≥2 项支持细菌性。
- 损伤穿刺校正：WBC校正 = WBC - RBC/700。
- 用例：WBC 2000、中性粒 90%、蛋白 2.0、CSF糖 1.5/血糖 6（0.25）→ 4/4，支持细菌性。
- 用例：WBC 80、中性粒 20%、蛋白 0.6、比值 0.6 → 0/4，倾向病毒性。
- 注意：明确标注不单独诊断。

## Padua
- 活动性肿瘤3、既往VTE 3、制动≥3天3、易栓症3、近期创伤/手术2、年龄≥70 1、心衰/呼衰1、急性心梗/卒中1、急性感染/风湿1、BMI≥30 1、激素治疗1。≥4 高危。
- 用例：肿瘤（3）+制动（3）+72岁（1）→ 7 分，高危。
- 用例：50 岁、无因素 → 0 分，低危。

## MME（CDC 2022 因子）
- 吗啡1、氢可酮1、羟考酮1.5、氢吗啡酮5、曲马多0.2、芬太尼贴剂(mcg/hr)2.4。
- 用例：羟考酮 40 mg/日 + 曲马多 200 mg/日 → 60+40=100 MME，高风险。
- 注意：美沙酮未纳入；MME 不用于直接剂量转换（交叉需减 25-50%）。手动计算器。

## 激素等效换算
- 泼尼松5 = 泼尼松龙5 = 甲泼尼龙4 = 曲安西龙4 = 氢化可的松20 = 可的松25 = 地塞米松0.75 = 倍他米松0.75。
- 用例：甲泼尼龙 40 mg → 泼尼松当量 50 mg；地塞米松等效 7.5 mg。
- 手动计算器。

## Fick 心排量
- CO = VO₂ / (1.34×Hgb(g/dL)×(SaO₂-SvO₂)×10)；VO₂ 缺省 125×BSA（Mosteller）。
- 用例：Hgb 120 g/L、SaO₂ 98、SvO₂ 68、170cm/70kg → BSA 1.81、VO₂ 226、差 4.02 mL/dL → CO ≈5.6 L/min，CI 3.1。
- 自动计算锚点 hgb；svo2/vo2 为新增字段。

## 对乙酰氨基酚列线图（Rumack-Matthew 150 线）
- 阈值 = 150 / 2^((t-4)/4)（4-24h 单次急性摄入）。
- 用例：4h、200 mg/L → ≥150，给 NAC。
- 用例：8h、60 mg/L → 阈值 75，低于治疗线。
- 用例：2h、180 → 提示过早，4h 复测。
- 手动计算器。

# Batch 3b

## Sgarbossa / Smith 改良标准
- 协调性 ST 抬高 ≥1mm=5 分；V1-V3 协调性 ST 压低 ≥1mm=3 分；不协调 ST 抬高 ≥5mm=2 分（原始）或 ST/S≤-0.25=2 分（Smith 改良）。
- 用例：协调性 ST 抬高 → 5 分，高度提示，按 STEMI 等效处理。
- 用例：仅 ST/S≤-0.25 → 2 分，改良标准阳性，建议紧急会诊。
- 注意：仅适用 LBBB/起搏心律；原始口径 ≥3 分特异性高、敏感性有限，阴性不排除。手动计算器。

## Duke IE 标准
- 确诊 = 2 主要 / 1 主要+3 次要 / 5 次要；可能 = 1 主要+1 次要 / 3 次要。
- 用例：血培养✓ + 超声✓ → 2 主要，确诊。
- 用例：发热+易感+血管现象（3 次要）→ 可能。
- 手动计算器；标准核对非最终诊断。

## AWOL
- 年龄≥80、倒拼 WORLD 失败、地点定向障碍、病情较重（护士判断）各 1 分；≥2 启动预防，筛查阳性 CAM/CAM-ICU 确认。
- 用例：85 岁+倒拼失败 → 2 分，中风险。
- 手动计算器。
